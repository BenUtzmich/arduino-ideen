# 🚀 Arduino Ideen

Willkommen im **Arduino Ideen** Repository! Hier sammeln wir kreative, spannende und gut dokumentierte Arduino- und Raspberry Pi-Projekte. Jedes Projekt ist so aufbereitet, dass es leicht nachgebaut werden kann – vom Anfänger bis zum Fortgeschrittenen.

## 🛠️ Standard-Projektstruktur

Jedes Projekt in diesem Repository folgt einer einheitlichen Struktur, um den Nachbau so einfach wie möglich zu machen:

```text
📁 Projektname/
├── 📄 README.md          → Vollständige Projektdokumentation (Bauteile, Anleitung)
├── 📄 code.ino           → Arduino-Sketch (vollständig kommentiert)
├── 📄 anleitung.pdf      → Druckfertige Anleitung (optional)
└── 📁 assets/            → Bilder, Schaltpläne und Diagramme
    ├── 🖼️ schaltplan.png
    └── 🖼️ verdrahtung.png
```

## 💡 Wie man die Projekte nutzt

1. **Repository klonen:**
   ```bash
   git clone https://github.com/DEIN_USERNAME/arduino-ideen.git
   ```
2. **Projekt auswählen:** Navigiere in den Ordner des gewünschten Projekts.
3. **Dokumentation lesen:** Öffne die `README.md` im Projektordner für die Bauteilliste und den Schaltplan.
4. **Code hochladen:** Öffne die `.ino`-Datei in der Arduino IDE und lade sie auf deinen Mikrocontroller hoch.
